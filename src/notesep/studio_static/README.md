# Studio interface

- `index.html` and `space.js` provide the hosted Studio interface.
- `note-editor.html` and `note-editor.js` provide the local note editor.
- `space.css`, `space-editor.css`, and `space-layout.css` style the hosted interface.
- `note-editor.css`, `note-editor-layout.css`, and `draw-mode.css` style the note editor.
- `upload-feedback.css` styles upload status messages.
- `audio-edit-values.mjs` and `score-edit.mjs` apply note edits.
- `audio-export.mjs` and `wav-decode.mjs` handle audio export and decoding.
- `assets/` contains the example manifest.
- `examples/` contains the example audio and score.
- `vendor/` contains browser libraries and their licenses.
