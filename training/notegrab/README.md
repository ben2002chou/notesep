# NoteGrab training

- `parent_contract.json` records the parent training settings.
- `adaptation_contract.json` records the instrument adaptation settings.
- `training_contract.json` records the continuation settings.
- `environment.json` supplies the model and augmentation settings.
- `data/` contains the training data readers and samplers.
- `models/` contains the training model and its training loop.

Start training from the repository root as shown in the main README.
