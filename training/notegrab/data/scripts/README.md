# NoteGrab data loaders

- `event_cluster_data.py` loads recorded score scenes.
- `library_balanced_sampling.py` balances training across source libraries.
- `native_sampling.py` samples instrument libraries for adaptation.
- `parent_balanced_training.py` balances crops for parent training.
- `target_cropped_training.py` crops examples around target notes.
- `track_bound_sampling.py` samples libraries and their sound identities.
