# NoteGrab model code

The source manifest checks the exact selected implementation files before they are loaded. `separator/` contains the separator architecture and data code; `gating/` contains the selective gate.

| File or folder | Purpose |
| --- | --- |
| `source_manifest.json` | SHA-256 checksums for the selected model source files. |
| `separator/` | Separator architecture, training scripts, and model helpers. |
| `gating/` | Selective-gate training and model implementation. |
